# Quy trình tách file Section View qua Data Shortcuts & cập nhật ngược Surface

**Tóm tắt:** Tách file trắc ngang chuyên biệt qua Data Shortcuts, Promote Surface để chỉnh sửa tự nhiên, sau đó Dref ngược lại vào file gốc để Rebuild Corridor an toàn.

## Vấn đề / Triệu chứng
Mô hình thiết kế lớn (bề mặt, cọc, corridor, trắc ngang) gộp chung 1 file khiến bản vẽ cực nặng, giật lag và dễ crash khi chỉnh sửa địa hình trắc ngang.

## Bối cảnh
Autodesk Civil 3D, quy trình làm việc dự án lớn với Data Shortcuts.

## Nguyên nhân
Mô hình Corridor tự động tái tạo liên tục khi chỉnh sửa bề mặt trên cùng một file làm cạn kiệt bộ nhớ RAM.

## Các bước xử lý
Quy trình 4 bước chuẩn phân tách file bằng Data Shortcuts:
Bước 1: File gốc chứa dữ liệu chính gồm Bề mặt khảo sát gốc, Tim tuyến Alignment (bao gồm cọc Sample Line, Profile trắc dọc) và Hành lang Corridor.
Bước 2: Tạo một file DWG riêng để xuất Trắc ngang (Section View file). File này lấy toàn bộ dữ liệu từ File gốc qua Data Shortcuts (Dref). Riêng Surface tự nhiên thì lấy từ file gốc rồi bấm PROMOTE độc lập để tiện chỉnh sửa đường địa hình trắc ngang (dùng visual tool hiệu chỉnh). Khi chỉnh sửa tại file này, đường thiết kế chưa nhảy vì Corridor là Reference Xref/Dref nên không bị lag hay crash.
Bước 3: Sau khi hiệu chỉnh xong địa hình trắc ngang, tạo Data Shortcut cho Surface tự nhiên mới từ chính file Trắc ngang này.
Bước 4: Mở lại File gốc: Dref lấy lại Surface tự nhiên mới từ file Trắc ngang. Chọn lại Target Surface của Corridor trỏ vào bề mặt tự nhiên mới rồi Rebuild Corridor. Các Profile trắc dọc cũng chọn lại Surface mới, sau đó xóa bỏ Surface tự nhiên cũ.

## Kết quả
Bản vẽ trắc ngang nhẹ mượt, chống crash CAD tuyệt đối, mô hình Corridor ở file gốc cập nhật trơn tru.

## Cảnh báo
- Khi Promote Surface ở file trắc ngang, cần đặt tên mới rõ ràng để phân biệt với bề mặt khảo sát ban đầu.
